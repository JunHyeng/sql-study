# 5단계: 데이터 분석가 포트폴리오

역할: 시니어 데이터 분석가 겸 커리어 멘토. SQL, Excel, Python을 각각 중심으로 한 실무형 프로젝트 3개를 만들고, 정리 → 인사이트 → 대시보드 → 발표까지 완성합니다.

| 프로젝트 | 중심 도구 | 주제(안) | 상태 |
|---|---|---|---|
| 1 | SQL + Excel | 이커머스 매출·고객 분석 (재구매율, 코호트) | 예정 |
| 2 | Python | 공공데이터 기반 분석 (정리·통계·시각화) | 예정 |
| 3 | SQL + BI | 경영 KPI 대시보드 + 결과 발표 자료 | 예정 |

주제는 4단계가 끝날 때 관심 분야와 지원하려는 직무에 맞춰 함께 확정합니다.
