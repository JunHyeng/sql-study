# 3강: NULL 다루기

## 오늘의 목표

- NULL이 "0"이나 "빈칸 글자"와 어떻게 다른지 설명할 수 있다.
- `IS NULL` / `IS NOT NULL`로 값이 없는 행을 찾을 수 있다.
- `IFNULL`, `COALESCE`로 NULL을 다른 값으로 바꿔 보여 줄 수 있다.

## 1. NULL은 "값이 없음(모름)"이다

`customers` 테이블을 조회해 보면 `phone` 열에 `[NULL]`이라고 표시된 칸이 있습니다.

```sql
SELECT name, phone FROM customers;
```

| 값 | 뜻 | 예시 |
|---|---|---|
| `0` | 숫자 0이라는 **값이 있음** | 재고 0개 |
| `''` (빈 글자) | 글자 수 0인 **값이 있음** | 연락처 칸을 일부러 비워 저장 |
| `NULL` | **값 자체가 없음 / 모름** | 연락처를 아예 입력하지 않음 |

엑셀로 치면 0이 들어 있는 칸과 아무것도 입력하지 않은 칸의 차이입니다. 실무 데이터에는 NULL이 정말 많습니다. 회원가입 때 선택 항목을 안 쓴 고객, 비회원 주문, 아직 퇴사하지 않은 직원의 퇴사일 같은 것들입니다.

## 2. NULL은 `=`로 찾을 수 없다 (가장 중요)

```sql
-- ❌ 오류는 안 나지만 결과가 0행
SELECT name FROM customers WHERE phone = NULL;

-- ✅ 올바른 방법
SELECT name FROM customers WHERE phone IS NULL;
```

이유: NULL은 "모르는 값"이라 **어떤 것과 비교해도 결과가 참도 거짓도 아닌 "모름(UNKNOWN)"**이 됩니다. `NULL = NULL`조차 "모름"입니다. 모르는 값 둘이 같은지 알 수 없기 때문입니다. WHERE는 **참인 행만** 남기므로 아무것도 안 나옵니다.

> [!WARNING]
> `= NULL`은 오류 없이 0행을 돌려줍니다. 2강 8번처럼 **조용히 틀리는** 유형이라 실무에서 특히 위험합니다. NULL을 찾을 때는 무조건 `IS NULL`.

### 예제 1: 연락처가 있는 고객만

```sql
SELECT name, phone
FROM customers
WHERE phone IS NOT NULL;
```

### 예제 2: 다른 조건과 함께

```sql
SELECT name, city
FROM customers
WHERE phone IS NULL
  AND city = '경기';
```

결과 2행.

## 3. NULL은 계산을 "오염"시킨다

NULL이 들어간 계산은 결과도 NULL이 됩니다. 모르는 값에 1을 더해도 모르는 값이기 때문입니다.

```sql
SELECT 100 + NULL;                    -- 결과: NULL
SELECT CONCAT('김민수', ' / ', NULL); -- 결과: NULL
```

`CONCAT`은 글자를 이어 붙이는 MySQL 함수입니다. 하나라도 NULL이면 전체가 NULL이 됩니다. 연락처가 없는 고객은 "이름 / 연락처"가 통째로 사라지는 거죠.

## 4. NULL을 다른 값으로 바꾸기: IFNULL, COALESCE

### IFNULL(값, 대신할값): MySQL 전용, 2개만

```sql
SELECT name,
       IFNULL(phone, '미등록') AS 연락처
FROM customers;
```

phone이 NULL이면 `'미등록'`, 아니면 원래 값이 나옵니다.

### COALESCE(값1, 값2, 값3, …): 표준 SQL, 여러 개 가능

```sql
SELECT name,
       COALESCE(phone, '미등록') AS 연락처
FROM customers;
```

왼쪽부터 보면서 **처음으로 NULL이 아닌 값**을 돌려줍니다. 예를 들어 `COALESCE(휴대폰, 집전화, '없음')`이면 휴대폰 → 집전화 순서로 있는 것을 쓰고, 둘 다 없으면 `'없음'`이 됩니다.

> [!TIP]
> `COALESCE`는 MySQL, Oracle, PostgreSQL 어디서나 됩니다. Oracle에는 `IFNULL` 대신 `NVL`이 있습니다. 하나만 익힌다면 **COALESCE**를 추천합니다.

## 5. 실무에서는 이렇게 쓰입니다

- "비회원 주문은 몇 건이에요?" → `WHERE customer_id IS NULL`
- "문자 발송 대상 뽑아 주세요" → `WHERE phone IS NOT NULL` (연락처 없는 사람에게는 못 보내니까)
- 보고서에 빈칸 대신 "미등록", 금액은 0으로 보여 주기 → `COALESCE(phone, '미등록')`, `COALESCE(할인금액, 0)`

엑셀 결산을 할 때 빈칸 때문에 합계나 평균이 이상하게 나온 경험이 있다면, SQL에서 그 역할을 하는 게 NULL입니다. 6강 집계 함수에서 이 문제를 다시 다룹니다.
