# 5강: 계산과 함수 (산술, 문자열, 날짜, CASE WHEN)

## 오늘의 목표

- SELECT에서 숫자를 계산하고 반올림할 수 있다.
- 문자열·날짜 함수로 값을 원하는 모양으로 바꿀 수 있다.
- `CASE WHEN`으로 조건에 따라 다른 값을 보여 줄 수 있다. (엑셀의 IF)

> [!NOTE]
> 함수는 **행 하나하나에** 적용됩니다. 10행에 함수를 쓰면 결과도 10행입니다. (여러 행을 하나로 합치는 SUM, COUNT 같은 함수는 6강에서 배웁니다)

## 1. 산술 연산과 반올림

| 연산 | 예시 | 결과 |
|---|---|---|
| `+` `-` `*` `/` | `price * 2` | 곱하기 |
| `%` 또는 `MOD()` | `10 % 3` | 나머지 1 |
| `ROUND(값, 자리)` | `ROUND(3636.36)` | 3636 (정수로 반올림) |
| | `ROUND(3.14159, 2)` | 3.14 |
| `FLOOR()` / `CEIL()` | `FLOOR(3.9)` / `CEIL(3.1)` | 3 / 4 (내림 / 올림) |

```sql
-- 부가세 10%를 뺀 공급가 (결산 업무에서 자주 쓰는 계산)
SELECT name,
       price,
       ROUND(price / 1.1) AS 공급가,
       price - ROUND(price / 1.1) AS 부가세
FROM menu;
```

> [!TIP]
> 엑셀의 `=ROUND(A2/1.1, 0)`과 같습니다. 엑셀로 결산했던 경험이 SQL에서 그대로 쓰입니다.

## 2. 문자열 함수

| 함수 | 하는 일 | 예시 | 결과 |
|---|---|---|---|
| `CONCAT(a, b, …)` | 이어 붙이기 | `CONCAT(name, '님')` | 김민수님 |
| `CHAR_LENGTH(s)` | **글자 수** | `CHAR_LENGTH('아메리카노')` | 5 |
| `LENGTH(s)` | **바이트 수** | `LENGTH('아메리카노')` | 15 |
| `LEFT(s, n)` / `RIGHT(s, n)` | 왼쪽 / 오른쪽 n글자 | `RIGHT('010-1111-2222', 4)` | 2222 |
| `SUBSTRING(s, 시작, 길이)` | 중간 잘라내기 | `SUBSTRING('010-1111-2222', 5, 4)` | 1111 |
| `REPLACE(s, 찾을것, 바꿀것)` | 바꾸기 | `REPLACE('010-1111-2222', '-', '')` | 01011112222 |
| `UPPER()` / `LOWER()` | 대문자 / 소문자 | `UPPER('abc')` | ABC |
| `TRIM(s)` | 앞뒤 공백 제거 | `TRIM('  서울 ')` | 서울 |

```sql
SELECT name,
       CONCAT(LEFT(name, 1), '**') AS 마스킹이름,     -- 김**
       REPLACE(phone, '-', '') AS 숫자만
FROM customers;
```

- SQL에서 글자 위치는 **1부터** 셉니다. (프로그래밍 언어는 보통 0부터)
- 함수 안에 함수를 넣을 수 있습니다. 안쪽부터 계산됩니다.
- 개인정보 마스킹(`김**`)은 실무에서 실제로 많이 쓰는 패턴입니다.

## 3. 날짜 함수

| 함수 | 하는 일 | 예시 (`join_date = '2025-01-15'`) | 결과 |
|---|---|---|---|
| `YEAR()` / `MONTH()` / `DAY()` | 연 / 월 / 일 꺼내기 | `MONTH(join_date)` | 1 |
| `CURDATE()` | 오늘 날짜 | `CURDATE()` | 오늘 |
| `DATEDIFF(끝, 시작)` | 두 날짜 사이 일수 | `DATEDIFF('2025-12-31', join_date)` | 350 |
| `DATE_ADD(날짜, INTERVAL n 단위)` | 날짜 더하기 | `DATE_ADD(join_date, INTERVAL 1 MONTH)` | 2025-02-15 |
| `DATE_FORMAT(날짜, 형식)` | 모양 바꾸기 | `DATE_FORMAT(join_date, '%Y년 %m월')` | 2025년 01월 |

`DATE_FORMAT`의 형식 기호: `%Y` 연(4자리), `%m` 월(2자리), `%d` 일, `%H` 시, `%i` 분.

```sql
-- 10월 주문만 (날짜 함수 + WHERE)
SELECT order_id, order_date
FROM orders
WHERE MONTH(order_date) = 10;
```

> [!NOTE]
> 날짜 함수 이름은 DB마다 많이 다릅니다. Oracle은 `TO_CHAR(날짜, 'YYYY')`, `SYSDATE` 등을 씁니다. 개념(연·월 꺼내기, 날짜 차이, 형식 바꾸기)은 같으니 개념 위주로 익히세요.

## 4. CASE WHEN: 조건에 따라 다른 값 (엑셀의 IF)

```sql
CASE
    WHEN 조건1 THEN 값1
    WHEN 조건2 THEN 값2
    ELSE 그외값
END
```

위에서부터 차례로 검사해서 **처음 참이 된 WHEN의 값 하나**를 돌려주고 멈춥니다. (3강 COALESCE처럼 "처음 만난 것"에서 멈춥니다)

```sql
SELECT name,
       price,
       CASE
           WHEN price >= 6000 THEN '프리미엄'
           WHEN price >= 5000 THEN '일반'
           ELSE '저렴'
       END AS 등급
FROM menu;
```

- 6000원짜리 치즈케이크는 첫 WHEN(`>= 6000`)에서 멈추니까 두 번째 WHEN도 참이지만 `'프리미엄'`이 됩니다. **순서가 중요합니다.**
- `ELSE`를 빼면 어떤 WHEN에도 안 걸린 행은 **NULL**이 됩니다.
- `END` 뒤에 `AS 별칭`을 붙입니다. `END`를 빠뜨리는 실수가 가장 흔합니다.

### 한 컬럼 값을 바꿀 때는 짧은 형태도 가능

```sql
SELECT name,
       CASE gender WHEN 'M' THEN '남' WHEN 'F' THEN '여' END AS 성별
FROM customers;
```

## 5. 실무에서는 이렇게 쓰입니다

- 공급가·부가세·할인가 계산 → 산술 + `ROUND`
- 전화번호 마스킹, 이름 마스킹 → `LEFT`, `RIGHT`, `CONCAT`
- "월별 가입자 수" → `DATE_FORMAT(join_date, '%Y-%m')` (6~7강에서 GROUP BY와 함께)
- 고객 등급, 가격대, 연령대 구분 → `CASE WHEN`

`CASE WHEN`은 분석 쿼리에서 가장 많이 쓰는 문법 중 하나입니다. 7강 GROUP BY와 합치면 "가격대별 판매량" 같은 분석을 할 수 있습니다.
