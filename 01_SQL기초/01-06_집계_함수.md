# 6강: 집계 함수 (COUNT, SUM, AVG, MIN, MAX)

## 오늘의 목표

- 여러 행을 **한 줄로 요약**하는 집계 함수 5개를 쓸 수 있다.
- `COUNT(*)`, `COUNT(컬럼)`, `COUNT(DISTINCT 컬럼)`의 차이를 설명할 수 있다.
- 집계 함수가 NULL을 어떻게 다루는지 알고 있다.

> [!NOTE]
> 5강 함수(`ROUND`, `LEFT`, `YEAR` …)는 **행마다** 하나씩 계산했습니다. 10행이면 결과도 10행.
> 오늘 배우는 집계 함수는 **여러 행을 모아 값 하나**로 만듭니다. 10행이 들어가면 결과는 **1행**입니다. 엑셀의 `SUM`, `COUNT`, `AVERAGE`, `MAX`, `MIN`과 같습니다.

## 1. 집계 함수 5개

| 함수 | 하는 일 | 엑셀 | 예시 | 결과 |
|---|---|---|---|---|
| `COUNT()` | 개수 | `COUNTA` | `COUNT(*)` | 12 |
| `SUM()` | 합계 | `SUM` | `SUM(price)` | 59000 |
| `AVG()` | 평균 | `AVERAGE` | `AVG(price)` | 4916.6667 |
| `MAX()` | 최댓값 | `MAX` | `MAX(price)` | 6500 |
| `MIN()` | 최솟값 | `MIN` | `MIN(price)` | 2500 |

```sql
SELECT COUNT(*)            AS 메뉴수,
       SUM(price)          AS 가격합계,
       ROUND(AVG(price))   AS 평균가격,
       MAX(price)          AS 최고가,
       MIN(price)          AS 최저가
FROM menu;
```

결과는 **딱 1행**입니다. 5강 함수와 합쳐서 `ROUND(AVG(price))`처럼 쓸 수 있습니다.

- `MAX`, `MIN`은 숫자뿐 아니라 **날짜**(가장 최근·가장 옛날), **글자**(가나다 마지막·처음)에도 씁니다.
- `SUM`, `AVG`는 숫자에만 씁니다.

## 2. WHERE와 함께: 거른 다음 집계

```sql
SELECT COUNT(*) AS 디저트수,
       SUM(price) AS 디저트가격합계
FROM menu
WHERE category = '디저트';
```

실행 순서는 **FROM → WHERE → 집계(SELECT)**입니다. 디저트 4행만 남긴 뒤 그 4행을 요약합니다.

## 3. COUNT 3형제 (중요)

| 쓰는 법 | 세는 것 | `orders` 테이블 결과 |
|---|---|---|
| `COUNT(*)` | **모든 행** | 18 |
| `COUNT(customer_id)` | customer_id가 **NULL이 아닌** 행 | 16 (비회원 2건 제외) |
| `COUNT(DISTINCT customer_id)` | NULL이 아닌 값의 **종류** 수 | 9 (같은 고객이 여러 번 주문해도 1명) |

```sql
SELECT COUNT(*)                    AS 전체주문,
       COUNT(customer_id)          AS 회원주문,
       COUNT(DISTINCT customer_id) AS 주문한고객수
FROM orders;
```

실무에서 "주문 건수"와 "주문한 고객 수"는 전혀 다른 숫자입니다. 이걸 헷갈리면 보고서가 통째로 틀립니다.

## 4. 집계 함수는 NULL을 건너뛴다

`COUNT(*)`만 빼고, 집계 함수는 **NULL인 칸을 아예 없는 것처럼** 무시합니다.

예를 들어 점수 4개가 `100, 80, NULL, 60`이면:

| 식 | 결과 | 이유 |
|---|---|---|
| `COUNT(*)` | 4 | 행은 4개 |
| `COUNT(점수)` | 3 | NULL 제외 |
| `SUM(점수)` | 240 | NULL 제외하고 더함 |
| `AVG(점수)` | **80** | 240 ÷ **3** (NULL 제외한 3개로 나눔) |
| `AVG(COALESCE(점수, 0))` | **60** | 240 ÷ **4** (NULL을 0으로 보고 4개로 나눔) |

> [!WARNING]
> **"NULL = 0점"으로 볼지, "NULL = 아직 모름(계산에서 제외)"으로 볼지에 따라 평균이 달라집니다.** 미응시자를 0점으로 칠지 말지 같은 문제입니다. SQL이 정해 주지 않으니, 분석하는 사람이 **기준을 정하고 보고서에 적어야** 합니다. (5강 8번처럼 애매하면 요청자에게 확인)

## 5. 자주 하는 실수: 일반 컬럼과 집계를 같이 쓰기

```sql
-- ❌ "가장 비싼 메뉴 이름"을 구하려는 의도
SELECT name, MAX(price) FROM menu;
```

MySQL 8.4에서는 오류가 납니다. `MAX(price)`는 12행을 1행으로 줄이는데, `name`은 12개 중 **어떤 걸 보여 줄지 정할 수 없기** 때문입니다.

```sql
-- ✅ 가장 비싼 메뉴 이름이 필요하면 4강 방법으로
SELECT name, price FROM menu ORDER BY price DESC LIMIT 1;
```

"이름별로", "분류별로"처럼 **그룹마다** 요약하고 싶다면, 그건 7강 `GROUP BY`의 역할입니다.

## 6. 실무에서는 이렇게 쓰입니다

- 대시보드 맨 위의 숫자 카드(KPI): "총 주문 수", "총 매출", "평균 객단가", "구매 고객 수"가 전부 집계 함수 한 줄입니다.
- 결산 업무에서 엑셀로 하던 합계·평균 검증을 SQL 한 번으로 끝낼 수 있습니다.

## 실습 문제

답안 칸에는 쿼리만 적어 주세요. 별칭은 따옴표 없이 쓰세요. 결과가 모두 **1행**이어야 합니다. 다 풀면 **"6강 답안 제출"**.

**문제 1.** 메뉴의 총 개수를 `메뉴수`라는 이름으로 조회하세요. (12)

```sql
select count(*) as 메뉴수 from menu;
```

**문제 2.** 전체 고객 수와 연락처가 있는 고객 수를 각각 `전체고객`, `연락처보유`라는 이름으로 한 번에 조회하세요. (10, 7)

```sql
select count(*) as 전체고객, count(phone) as 연락처보유 from customers;
```

**문제 3.** 메뉴 평균 가격을 **정수로 반올림**해서 `평균가격`이라는 이름으로 조회하세요. (4917)

```sql
select round(avg(price)) as 평균가격 from menu;
```

**문제 4.** 메뉴의 최고가와 최저가, 그리고 둘의 차이를 각각 `최고가`, `최저가`, `가격차이`라는 이름으로 조회하세요. (6500, 2500, 4000)

```sql
select max(price) as 최고가, min(price) as 최저가, (max(price) - min(price)) as 가격차이 from menu;
```

**문제 5.** 디저트 메뉴의 개수, 가격 합계, 평균 가격(정수 반올림)을 `디저트수`, `가격합계`, `평균가격`이라는 이름으로 조회하세요. (4, 20500, 5125)

```sql
select count(*) as 디저트수, sum(price) as 가격합계, round(avg(price)) as 평균가격 from menu where category = '디저트';
```

**문제 6.** `orders` 테이블에서 전체 주문 수, 회원 주문 수, **비회원 주문 수**를 각각 `전체주문`, `회원주문`, `비회원주문`이라는 이름으로 조회하세요. (18, 16, 2) 힌트: 비회원 주문 수는 두 COUNT의 차이로 구할 수 있습니다.

```sql
select count(*) as 전체주문, count(customer_id) as 회원주문, (count(*) - count(customer_id)) as 비회원주문 from orders;
```

**문제 7.** 한 번이라도 주문한 **서로 다른 회원 수**를 `구매고객수`라는 이름으로 조회하세요. (9)

```sql
select count(distinct customer_id) as 구매고객수 from orders;
```

**문제 8.** `order_items` 테이블에서 총 판매 수량과, 주문 상세 한 줄당 평균 수량(소수 둘째 자리까지 반올림)을 `총판매수량`, `평균수량`이라는 이름으로 조회하세요. (40, 1.43)

```sql
select sum(quantity) as 총판매수량, round(avg(quantity), 2) as 평균수량 from order_items;
```

**문제 9.** 가장 먼저 가입한 날짜와 가장 최근에 가입한 날짜를 `첫가입일`, `최근가입일`이라는 이름으로 조회하세요. (2025-01-15, 2025-09-14)

```sql
select min(join_date) as 첫가입일, max(join_date) as 최근가입일 from customers;
```

**문제 10. (함정 문제)** 아래 쿼리를 실행해 보고, 오류 메시지와 오류가 나는 이유를 적은 뒤, "가장 싼 메뉴의 이름과 가격"을 구하는 올바른 쿼리를 쓰세요.

```sql
SELECT name, MIN(price) FROM menu;
```

오류 메시지와 이유:
>name에 나오는 데이터는 많은데, min 집계함수를 사용한 price 데이터 값은 1개라 오류 발생

올바른 쿼리:

```sql
SELECT name, price FROM menu order by price limit 1;
```

### 피드백: ROUND와 SUM의 차이는 "결과가 몇 행이냐"

질문은 계산 방법(반올림)이 아니라 **결과 행 수**를 물었습니다.

| 함수 종류 | 예시 | 12행이 들어가면 | 비유 |
|---|---|---|---|
| **행 단위 함수** (5강) | `ROUND`, `LEFT`, `YEAR`, `CASE` | **12행** 그대로 나옴 | 엑셀에서 수식을 아래로 **드래그** |
| **집계 함수** (6강) | `SUM`, `COUNT`, `AVG`, `MAX`, `MIN` | **1행**으로 줄어듦 | 엑셀 맨 아래 **합계 칸** 하나 |

이 차이 때문에 10번 문제에서 오류가 났습니다. `name`은 행 단위라 12행을 내려는데, `MIN(price)`는 1행으로 줄이려고 해서 행 수가 안 맞는 겁니다. 이 개념이 바로 7강 GROUP BY의 출발점이라 7강 맨 앞에서 한 번 더 확인합니다.
