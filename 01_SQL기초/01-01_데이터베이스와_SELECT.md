# 1강: 데이터베이스와 SELECT

## 오늘의 목표

- 데이터베이스, 테이블, 행, 열이 무엇인지 말로 설명할 수 있다.
- `SELECT ... FROM ...`으로 원하는 컬럼만 꺼낼 수 있다.
- `AS`로 컬럼 이름을 바꿔 보여 줄 수 있다.

## 1. 데이터베이스는 "엑셀 파일 묶음"이다

엑셀로 결산 업무를 해 보셨다면 이미 절반은 알고 계십니다.

| 엑셀 | 데이터베이스 |
|---|---|
| 엑셀 파일 (통합 문서) | **데이터베이스** (`cafe`) |
| 시트 하나 | **테이블** (`menu`, `customers` …) |
| 머리글 (A열 "이름", B열 "가격") | **열 / 컬럼** (`name`, `price`) |
| 데이터 한 줄 | **행 / 레코드** (아메리카노, 4000원) |

차이점은 두 가지입니다.

1. **열마다 자료형이 정해져 있다.** `price` 열에는 숫자만, `name` 열에는 글자만 들어갑니다. 엑셀처럼 한 칸에 아무거나 넣을 수 없어서 데이터가 깨끗하게 유지됩니다.
2. **마우스 대신 문장(SQL)으로 요청한다.** "menu 시트에서 이름과 가격만 보여 줘"를 SQL로 쓰면 `SELECT name, price FROM menu;`가 됩니다.

> [!TIP]
> SQL(Structured Query Language)은 "데이터에게 질문하는 언어"입니다. 질문 하나를 **쿼리(query)**라고 부릅니다.

## 2. SELECT의 기본 문장

```sql
SELECT 보여줄_컬럼
FROM   테이블_이름;
```

- `SELECT` = "무엇을 보여 줄까?"
- `FROM` = "어느 테이블에서?"
- 끝의 `;`는 문장의 마침표입니다. 쿼리가 여러 개일 때 구분해 줍니다.

### 예제 0: 사용할 DB 고르기 (MySQL)

```sql
USE cafe;
```

MySQL 서버 안에는 DB가 여러 개 있을 수 있어서, "지금부터 `cafe` DB를 쓴다"고 먼저 알려 줍니다. DBeaver에서 `cafe`를 우클릭해 SQL 편집기를 열었다면 생략해도 됩니다.

### 예제 1: 전체 보기

```sql
SELECT * FROM menu;
```

`*`는 "모든 컬럼"이라는 뜻입니다. 결과: 메뉴 12행 × 5열.

### 예제 2: 원하는 컬럼만 보기

```sql
SELECT name, price
FROM menu;
```

컬럼은 쉼표로 구분하고, **적은 순서대로** 결과에 나옵니다. `SELECT price, name`이라고 쓰면 가격이 먼저 나옵니다.

### 예제 3: 별칭(AS) 붙이기

```sql
SELECT name  AS 메뉴명,
       price AS 가격
FROM menu;
```

결과 화면의 머리글만 바뀝니다. 실제 테이블의 컬럼 이름은 그대로입니다. 보고서용 결과를 뽑을 때 자주 씁니다.

### 예제 4: 계산한 값 보여 주기

```sql
SELECT name,
       price,
       price * 1.1 AS 부가세포함가격
FROM menu;
```

SELECT에는 컬럼뿐 아니라 **계산식**도 쓸 수 있습니다. 원래 테이블에 없는 열이 결과에만 새로 생깁니다.

## 3. 꼭 기억할 규칙

- SQL 키워드(`SELECT`, `FROM`)는 대소문자를 가리지 않습니다. 하지만 **키워드는 대문자, 테이블·컬럼은 소문자**로 쓰는 게 실무 관례라 읽기 편합니다.
- 줄바꿈과 들여쓰기는 마음대로 해도 결과가 같습니다. 컬럼이 많으면 한 줄에 하나씩 쓰세요.
- 쿼리 실행은 DBeaver에서 `Ctrl + Enter`(커서가 있는 쿼리 하나), 여러 개를 한꺼번에 실행할 때는 `Alt + X`입니다.
- 글자 값은 작은따옴표 `'아메리카노'`로 감쌉니다. (다음 강에서 많이 씁니다)
- 실무 팁: `SELECT *`는 구경할 때만 쓰고, 보고서·프로그램에는 필요한 컬럼을 직접 적습니다. 컬럼이 수십 개인 테이블에서는 `*`가 느리고, 무엇을 쓰는지 알아보기 어렵기 때문입니다.

## 4. 실무에서는 이렇게 쓰입니다

마케팅팀이 "고객 이름이랑 연락처 목록 좀 뽑아 주세요"라고 하면, 데이터 담당자는 고객 테이블 전체가 아니라 필요한 두 컬럼만 꺼냅니다. 개인정보는 필요한 만큼만 꺼내는 것이 원칙이라, 컬럼을 골라 쓰는 습관이 실제로 중요합니다.

### 피드백 1: 행과 열 (가장 중요)

- **행(row) = 가로 한 줄** = 데이터 한 건. 예: `아메리카노 | 커피 | 4000`
- **열(column) = 세로 한 줄** = 항목 하나. 예: `price` 열에는 모든 메뉴의 가격이 세로로 쌓여 있음
- 엑셀로 치면 행은 1, 2, 3… 번호가 붙은 줄, 열은 A, B, C… 알파벳이 붙은 줄입니다.
- 테이블은 "표"도 맞지만, 더 정확히는 **엑셀 시트 하나**입니다. DB = 엑셀 파일, 테이블 = 시트.

### 피드백 2: 별칭에 작은따옴표 쓰지 않기

```sql
-- 작성한 쿼리 (MySQL에서는 실행되지만 권장하지 않음)
SELECT name AS '메뉴 이름' FROM menu;

-- 권장 1: 띄어쓰기를 빼고 따옴표 없이
SELECT name AS 메뉴이름 FROM menu;

-- 권장 2: 띄어쓰기가 꼭 필요하면 백틱(`) 사용 (키보드 숫자 1 왼쪽)
SELECT name AS `메뉴 이름` FROM menu;
```

이유: 작은따옴표 `'...'`는 SQL에서 **글자 값**(예: `'서울'`)을 뜻합니다. 별칭에도 쓰면 나중에 WHERE나 ORDER BY에서 헷갈리고, Oracle·PostgreSQL에서는 오류가 납니다. 2강부터 작은따옴표를 많이 쓰게 되니 지금 구분해 두세요.

### 피드백 3: 답안 칸 작성법

답안 앞에 `-- `를 붙이면 **주석**(실행되지 않는 메모)이 됩니다. 답안 칸에는 `-- ` 없이 쿼리만 적어 주세요. 주석은 설명을 달 때 씁니다.

```sql
-- 2026년 기준 나이 계산
SELECT name, 2026 - birth_year AS 나이 FROM customers;
```
