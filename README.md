## 공부 방법 (매 수업 공통)

1. 수업 노트를 읽는다 → 2. DBeaver에서 `cafe` DB(MySQL)에 예제 쿼리를 직접 실행한다 → 3. 노트 맨 아래 **실습 문제**의 답안 칸에 쿼리를 적는다 → 4. 채팅에 "N강 답안 제출"이라고 말한다 → 5. 채점·피드백을 받고 [오답노트](오답노트.md)에 정리한다 → 6. 이해 확인 질문을 통과하면 다음 수업.
