# 2강 복습: JOIN 혼자 풀기 세트

2강에서 힌트를 받아 풀었던 개념(SELF JOIN, fan-out, ON vs WHERE, 없는 것 찾기)을 **다른 상황**으로 다시 풉니다. 목표는 정답보다 **혼자 생각하는 순서를 몸에 익히는 것**입니다.

## 규칙

1. 문제마다 **쿼리를 쓰기 전에** 아래 "생각 메모" 3줄을 먼저 적습니다.
2. **15분**은 혼자 고민합니다. 틀려도 괜찮으니 일단 실행해 봅니다.
3. 막히면 채팅에 "복습 N번 힌트 1"이라고 보내 주세요. **한 줄짜리 힌트**만 드립니다. 그래도 막히면 "힌트 2".
4. 답안 아래에 **몇 번째 힌트로 풀었는지**(혼자 / 힌트 1 / 힌트 2) 적어 주세요. 다음 강의 난이도를 조절하는 데 씁니다.

## 생각 메모 (쿼리 짜기 전에 3줄)

```
① 결과 1줄 = 무엇? (예: 직원 1명, 고객 1명, 지역 1개)
② 필요한 테이블과 역할 (예: employees e = 직원, employees m = 상사)
③ 조건은 어디에? (ON = 붙일 행 고르기 / WHERE = 행 거르기 / HAVING = 묶음 거르기)
```

> [!TIP]
> 이 3줄은 실무 시니어들이 머릿속으로 하는 과정을 글로 꺼낸 것입니다. 처음엔 귀찮아도 몇 번 쓰다 보면 저절로 머릿속에서 돌아갑니다. 막혔을 때 **3줄 중 어디서 막혔는지** 보면 무엇을 물어봐야 할지도 분명해집니다.

**복습 6. (코드 리뷰)** 신입 사원이 "고객별 **결제금액**(매출 − 쿠폰)"을 아래처럼 뽑았는데, 최나연 고객의 결제금액이 실제보다 **31,000원 적게** 나왔다고 합니다. 원인을 **무엇이 → 왜 → 어떻게** 순서로 설명하세요. (고친 쿼리는 4강 서브쿼리에서 배우니 **설명만** 쓰면 됩니다)

```sql
SELECT c.customer_id, c.name,
       SUM(oi.unit_price * oi.quantity) - SUM(o.coupon_amount) AS 결제금액
FROM customers c
JOIN orders o       ON c.customer_id = o.customer_id
JOIN order_items oi ON o.order_id = oi.order_id
WHERE o.status = '배송완료'
GROUP BY c.customer_id, c.name;
```
